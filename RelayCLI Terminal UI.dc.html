16-color fallback. accent→blue, running→cyan, waiting→magenta, success→green, danger→red, warning→yellow, muted→brightblack. Hue order is preserved so muscle memory survives the downgrade.
Contrast. Every hue clears 4.5:1 on its own base — the lowest is waiting at 4.8:1 dark / 5.9:1 light. Nothing is used at dim intensity except frame rules.
Never color-only. Each state ships a glyph and, in lanes, a word. Removing color removes emphasis, never information — proven in the NO_COLOR pass below.

Progress without a percentage. Total work is unknown, so a lane reports only measured facts: elapsed, tool count, tokens, cost. No bar can lie about completion because there is no bar.
The lease conflict gets a line of its own. Holder, duration, queue position, estimate, and three keys that resolve it. It is a decision, not a log entry, so it is indented under the waiter rather than buried in a stream.
Permission never steals the screen. a3 is marked ? in its lane and in the key strip; a1 keeps working. You answer on your schedule with y/n or open it full-size.
Alignment does the grouping. Model, tokens, cost, and time sit in fixed right-aligned columns so they scan vertically as one table — that is what a scrolling log cannot do.

COPY-PASTE
The transcript has no left frame column and no right frame column — only a 1-col gutter of spaces. Selecting any run of transcript rows yields clean text. Only the permission band and inline diff previews draw a full box, and both are ephemeral by design.
MOTION — WHAT MOVES, AND HOW OFTEN
Spinner — 10 braille frames at 90ms. One shared clock for all lanes, so spinners tick in unison instead of shimmering independently.
Frame ceiling — the whole TUI redraws at most 15fps, and only regions whose model changed. Token counters coalesce to 4 updates/sec; cost to 1/sec.
Streaming text — appended, never re-laid-out. A long agent message does not reflow rows above it.
Never animates — the budget meter, lane order, diff content, and anything in the permission band. A moving target you must answer is hostile.
Lane reordering — only on state change, and only at grouping boundaries; never on token or cost updates.
Reduced motion / dumb terminals — NO_MOTION=1 or a non-TTY replaces the spinner with a static ◆ and drops to 2fps. Piped output prints one line per event and no control codes at all.

RATIONALE — THE THREE I WOULD DEFEND, AND WHAT I REJECTED
1 · The lane list is pinned and bounded
Everything else in this category scrolls, which means the answer to "what is happening right now" is always somewhere you are not looking. Pinning costs up to nine rows of transcript. That is the single most expensive decision in the design and the one that makes the screenshot test pass: at a glance you see four agents, four models, four costs, and one blocker. Bounding it matters as much as pinning it — a pinned region that can grow to twenty rows is just a second scroll region.
2 · Lease conflicts are a first-class state, not a log line
The blocked lane names the holder, the duration, the queue position, an estimate, and three keys that end the standoff. A user who cannot see why an agent is idle assumes the tool is broken; a user who can see it waits calmly. This is also why the plan screen forecasts contention before you approve — the blocked state should be a prediction coming true, not a surprise.
3 · No fake progress, anywhere
Agent work has no denominator. Every progress-shaped element here reports something measured: elapsed, tool count, tokens, dollars, tests passed. The one bar in the product is the budget meter, and it has a real denominator you set yourself. A percentage that is really a guess teaches users to distrust every number on the screen, including the ones that are costing them money.
Rejected: a drawn DAG. Box-and-arrow graphs in a character grid eat six rows to convey what indentation conveys in one, and they break the moment a task has two parents. Indentation plus ├─ └─ scales to any shape and stays copy-pasteable.
Rejected: split-pane multi-transcript. Four live streams at 30 columns each is four unreadable columns. One transcript with a merged role-prefixed mode gives the same coverage with legible line lengths, and the lane list already carries the parallel state.
Rejected: color-coding agents. Tempting, and it fails at four agents plus seven semantic colors, in 16-color mode, and under NO_COLOR. Identity lives in the id and role mark; color stays reserved for state, which is the thing you need to see peripherally.
