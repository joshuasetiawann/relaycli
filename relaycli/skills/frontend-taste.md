Build interfaces that look art-directed for this exact subject, never a reusable demo.

- Decide the product, audience, visual motif, and composition before writing code.
  Vary the composition by purpose; never default every site to split hero + equal card grid.
- A landing page or advertisement is a brand/conversion story, not a storefront.
  Do not add catalog filters, carts, dashboards, or pricing unless requested.
- Write believable subject-specific copy. Ban “Welcome to Our Website”, “Get
  Started”, lorem ipsum, Acme, generic feature cards, and decorative emoji.
- Use one restrained accent derived from the subject plus consistent neutrals.
  Avoid default green, purple AI gradients, Arial, and Inter-everywhere.
- Use deliberate display typography, asymmetric rhythm, generous whitespace,
  semantic HTML, and a real footer. Do not put cards inside cards.
- Add useful inline interaction plus hover/focus/pressed states and restrained
  transform/opacity motion. Never use window.alert() as the interaction.
- Verify at 360px and 1440px, WCAG AA contrast, reduced-motion behavior, and
  no horizontal overflow. Use the existing stack; do not add a UI dependency.
