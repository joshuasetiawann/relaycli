# RelayCLI Production Audit — 2026-08-21

## Outcome

RelayCLI is a local release candidate after a full discovery, repair, security,
Ollama, CLI, desktop, packaging, and regression pass on Windows with CPython
3.12.10 and 3.13.15. The audit changed production code only where a failure was
reproduced or a concrete trust-boundary gap was demonstrated.

The detailed code graph is in `graphify-out/GRAPH_REPORT.md`; its interactive
view is `graphify-out/graph.html`.

## Architecture discovered

- Typer/Rich CLI and REPL feed a provider-neutral agent loop.
- Pydantic Settings merges explicit arguments, environment, filtered project
  `.env`, and user TOML configuration.
- LiteLLM normalizes cloud and Ollama chat completions, streaming, tool calls,
  usage, timeouts, and provider errors.
- A permission manager and project-root resolver guard filesystem and command
  tools; leases coordinate parallel writers.
- Sequential relay and task-graph schedulers share budgets, role routing,
  blackboard state, reporters, and capability-restricted tool registries.
- The desktop app is a stdlib threaded HTTP server serving local HTML/CSS/JS
  and a polling JSON event API.
- MCP processes, trusted Python plugins, built-in/user/project skills, local
  memory, and Ollama discovery extend the core.

Graphify found 3,901 nodes, 10,769 retained edges, 136 communities, and no
import cycles. The most connected abstractions are `PermissionMode`, `Settings`,
`WebSession`, `ProjectContext`, `PermissionManager`, and `ToolContext`.

## Defects fixed

| Severity | Area | Reproduced problem | Repair |
|---|---|---|---|
| High | patch tool | `../` headers could write outside the project; a fixed temp filename could follow a planted link | validate both diff header paths, validate again in fallback, use exclusive random temp files |
| High | config/keys | Settings/AppConfig repr could include live provider keys | mark all key/raw fields `repr=False` and add regressions |
| High | project `.env` | 9Router could be enabled and redirected by repository-local dotenv values | filter enable/base URL aliases and validate HTTP(S) base URLs |
| High | web fetch | arbitrary URL fetch allowed private/loopback/metadata targets and unbounded reads | public-DNS/redirect validation, scheme/userinfo checks, 1 MiB read cap |
| High | process lifecycle | Windows timeout/stop killed only the shell leader, leaving children alive | create process groups and use System32 `taskkill /T /F` with fallback |
| High | MCP lifecycle/keys | closing a Windows MCP client left descendants alive; ambient provider keys were inherited | terminate the MCP process tree and scrub `*_API_KEY` unless explicitly mapped |
| High | dependencies | 30 advisories across six installed packages | upgrade fixed versions, lock resolution; post-fix audit is clean |
| Medium | settings | explicit Python field-name overrides were ignored when a validation alias existed | enable `populate_by_name` and test key/Ollama overrides |
| Medium | desktop HTTP | malformed cursor/content-length/JSON could crash a handler; body was unbounded | typed parsing, 400/413 responses, 1 MiB cap, CSP/nosniff/no-store |
| Medium | long sessions | server event list and chat DOM grew without a ceiling | monotonic bounded 2,000-event buffer and 400-message DOM cap |
| Medium | Windows UI | Rich 15 reported/clamped explicit widths, selecting wrong layouts | central `console_width()` using explicit/OS width |
| Medium | search | an AccessDenied `rg.exe` shim disabled search instead of falling back | treat any `OSError` as capability failure and use Python search |
| Low | Ollama errors | missing model was mislabeled as an unreachable server | emit a specific `ollama pull <model>` recovery hint |
| Low | packaging tests | uv-managed Python without bundled pip failed the wheel contract test | use uv's standards-compliant wheel builder fallback |

## Desktop redesign and UX verification

The existing Slate Instrument foundation was retained and the supplied desktop
reference was implemented as a darker cobalt orchestration workspace:

- the lane canvas now presents Orchestrator → Planner → Coder → Reviewer as an
  interactive flow with animated live/retry connections, selection, zoom, and
  drag-to-pan;
- node selection stays synchronized with the four-agent inspector;
- the terminal defaults to a persistent collapsed strip and can be resized or
  expanded without hiding agents;
- narrow screens now keep the logo, model, mode, and configuration hierarchy;
- the run inspector defaults to an on-demand sheet instead of being laid out
  beneath and covered by the terminal;

- chat, canvas, terminal, and inspector have explicit ownership of limited
  vertical space;

- CSP, favicon, and focusable labeled controls remain functional.

All had zero horizontal document overflow, zero external requests, zero console
errors, and zero unlabeled buttons. The mobile inspector open/close flow ended

## Known limitations and residual risk

1. Small local models are not equivalent to large hosted models. The audited
   1.5B model ignored strict JSON formatting and missed an early fact in an
   8K-token repetitive prompt. RelayCLI stayed stable; model selection remains
   a quality decision.
2. Python plugins run with full interpreter privileges after installation. The
   install prompt and manifest describe this trust act; capabilities are not a
   sandbox.
3. Non-loopback desktop binding is intentionally unauthenticated. Default
   binding is loopback, Host/Origin are checked, and a prominent warning is
   printed for LAN binding. Production remote use still needs an authenticating
   reverse proxy or a future native auth layer.
4. Public-DNS validation materially reduces SSRF, but a DNS rebinding race
   between validation and connection is not eliminated by stdlib urllib.
5. Root path checks do not provide Linux `openat2(RESOLVE_BENEATH)` semantics;
   a concurrent local attacker with write access can still create a narrow
   time-of-check/time-of-use race. RelayCLI runs unprivileged.
6. Bandit reports zero high-severity findings and eight medium findings. The
   remaining medium reports are known URL-open/static-endpoint or explicit
   non-loopback-bind heuristics. Ruff reports 373 repository-wide style/debt
   findings, mostly import ordering and modernization; compile and behavior
   tests are clean, but this should become a separately baselined lint project.
7. Nine tests are platform-conditional on Windows (POSIX permission/symlink/
   shell checks). CI should continue running Linux and macOS before publishing.
8. Live paid cloud-provider calls were not made: offline rejection, key
   resolution, authentication errors, and mocked provider adapters are tested,
   but release staging should smoke-test each supported provider with disposable
   credentials and strict spend limits.
9. Graphify's semantic merge reported 585 dangling raw endpoints and collapsed
   1,314 directed/1,327 undirected duplicates. The graph is usable and schema-
   valid, but those extraction-quality warnings should be addressed before
   treating every inferred path as authoritative.
